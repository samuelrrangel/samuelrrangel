### Hi there!

I'm a full-stack developer from Brazil, working on web applications,
backend services, and the infrastructure that keeps them running.

My day-to-day work includes evolving an auction platform and its ERP:
building integrations, modernizing legacy systems, improving user
workflows, and maintaining production applications.

- **Development:** PHP/Symfony, JavaScript/TypeScript, Vue/Nuxt, Python,
  and MySQL.
- **Infrastructure:** hands-on work with AWS, Docker, Terraform, and
  GitHub Actions, including deployments, database operations, and
  environment automation.
- **Currently exploring:** system design, application security,
  observability, and reliable background processing.
- **Outside work:** I build small projects and explore Linux,
  automation, and systems programming.

### Side projects

- [Torquemada](https://github.com/razorzinho/torquemada):

- [Saint Jerome](https://github.com/razorzinho/saint_jerome):
